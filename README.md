# Persian Scheduler 🇮🇷

A modern Persian calendar and scheduling application built with **Next.js** and **TypeScript**.

[View Live Demo](https://your-username.github.io/your-repository/)

## ✨ Features

* 📅 Persian (Jalali) calendar
* 🗓️ Event and schedule management
* 🇮🇷 Full Persian / RTL support
* 📱 Responsive design
* ⚡ Fast and modern UI
* 🎨 Modern component-based architecture

## 🛠️ Tech Stack

* **Next.js**
* **React**
* **TypeScript**
* **Tailwind CSS**
* **shadcn/ui**

## 🚀 Getting Started

### Prerequisites

Make sure you have Node.js installed on your machine.

### Installation

Clone the repository:

```bash
git clone https://github.com/your-username/your-repository.git
```

Navigate to the project directory:

```bash
cd your-repository
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.
